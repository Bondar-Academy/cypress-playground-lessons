# Cypress UI Testing Mastery — Lessons

Source code for the lessons demonstrated in the [**Cypress UI Testing Mastery**](https://bondaracademy.com/programs/cypress-ui-testing-mastery) program by [Bondar Academy](https://bondaracademy.com).

Every lesson lives in its **own branch**. To review the code for a particular lesson, switch to the corresponding branch:

```bash
git clone https://github.com/Bondar-Academy/cypress-playground-lessons.git
cd cypress-playground-lessons
npm install

git checkout <lesson-branch-name>
npx cypress open
```

The `master` branch contains only the base project setup — no lesson code.
